Questions

Everything else, answered.

Still curious? Write to hello@plotxyz.ai.

Is Plot Docs really free?

Yes. The app is free and open source. With your own API key, there is no subscription. Pro and Team add hosted AI, sync and admin features for people who want them.

Does it open Microsoft Word, Excel and PowerPoint files?

Natively. Plot Docs reads and writes .docx, .xlsx and .pptx, and only rewrites the parts you edit. Everything else survives byte-for-byte, so the file keeps working in Microsoft Office.

Where do my files go?

Nowhere. Opening, editing, saving and converting happen on your device. AI requests go to the provider you configure, using your key. We don't run your documents through our servers.

Which AI models can I use?

OpenRouter, Anthropic, OpenAI, Google Gemini, DeepSeek, Qwen, Kimi, GLM, Mistral, Grok, MiniMax and any OpenAI-compatible endpoint, including local servers like Ollama and LM Studio.

Can I use it offline?

Yes, with local models. File editing and conversion always work offline. Cloud AI features need a connection to your chosen provider.

Can my coding agent drive it?

Yes. Plot Docs ships a command line and an MCP server, so Claude Code, Codex, Cursor and other agents can create, read and edit real Office files on your machine.
